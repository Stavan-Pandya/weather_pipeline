# Weather API ETL Pipeline

A Data Engineering project built using Python, pandas, SQLite, and Weather API.

# Features

* Real-time weather extraction using API
* Data transformation using pandas
* CSV data storage
* SQLite database loading
* Weather analytics and visualization

# Technologies Used

* Python
* pandas
* requests
* SQLite
* SQLAlchemy
* matplotlib

# Project Structure

weather_pipeline/
│
├── data/
├── database/
├── output/
├── scripts/
├── main.py
└── requirements.txt

# Run Project

```bash
python main.py
```
